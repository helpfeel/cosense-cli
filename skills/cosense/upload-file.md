# Cosenseにファイルをアップロードする手順書

CLI コマンドの仕様や実行形式は [SKILL.md](SKILL.md) を参照する。
各コマンドの正確な引数・出力フォーマットは `cosense uploadFile --help` を見る。

## ワークフロー

### 手順1: `uploadFile` でアップロードする

アップロード先projectのURLとローカルファイルのパスを渡す。出力の `embedUrl` に注目する。次の手順の記法選択に使う。

`embedUrl` 末尾の拡張子は元のファイル名から引き継がれる。拡張子が中身と食い違っているファイルは埋め込み表示の判定も誤るので、アップロード前にファイル名を直す。

### 手順2: 埋め込み記法を選ぶ

埋め込み表示になるかどうかを、Cosenseの記法parserは `embedUrl` 末尾の拡張子で判定する。contentTypeは判定に使われない。

- 画像・動画・音声: `[embedUrl]`。本文中に画像・動画・音声プレイヤーとして埋め込み表示される
- それ以外（PDFやテキスト等のドキュメント）: `[ファイル名 embedUrl]`。埋め込み表示されないファイルはリンクテキストが無いと生URLが並ぶだけになり、何のファイルか読み手に伝わらない。リンクテキストはファイル名そのままでなく、内容を表す言葉にしてもよい

### 手順3: ページに埋め込む

選んだ記法の行をページ本文に書き込む。編集は [edit-page.md](edit-page.md) のワークフローに従う。
